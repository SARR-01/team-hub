# Message Improver Translator

This is a web application for improving and translating messages. 
The app features both a React frontend and a Python/Flask backend.

## Features
- Message improvement suggestions
- Language translation support

## Getting Started

### Prerequisites
- Node.js >= 14.x
- Python >= 3.6

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/SARR-01/team-hub.git
   cd team-hub
   ```
2. For the frontend:
   ```bash
   cd frontend
   npm install
   ```
3. For the backend:
   ```bash
   cd backend
   pip install -r requirements.txt
   ```

### Usage
- For the frontend:
   ```bash
   npm start
   ```
- For the backend:
   ```bash
   python app.py
   ```
